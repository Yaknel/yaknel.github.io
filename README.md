Personal Website

- `content/paginas/` textos de las páginas (Home, About, Somatics, Portfolio, Talleres, Links, políticas…)
- `content/escritos/` poemas y textos publicados
- `content/blog/` artículos largos
- `assets/imagenes-urls.txt` lista de imágenes de la web antigua; `./descargar-imagenes.sh` las descarga en `assets/img/`
